#  Apprendre HTML5 et CSS3

Ce projet regroupe les notions apprises dans le cours [Créez votre site web avec HTML5 et CSS3](https://openclassrooms.com/fr/courses/1603881-creez-votre-site-web-avec-html5-et-css3) d'OpenClassrooms.

##  Notions abordées

- **HTML5** : structurer une page web (titres, paragraphes, liens, images, formulaires).
- **CSS3** : mettre en forme les pages (couleurs, polices, marges, bordures).
- **Flexbox et Grid** : organiser les éléments d'une page.
- **Responsive Design** : adapter un site aux différentes tailles d'écran.

##  Objectif

Acquérir les bases du développement web pour créer des pages modernes, structurées et responsives.
